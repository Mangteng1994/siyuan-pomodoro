# 强制模式：休息时全屏遮罩（v0.1.12）

## 为什么做

现在休息太容易被无视：微休息只是 300×250 的置顶小窗，短休息、长休息只在迷你窗里倒计时，眼睛还停在原来的窗口上，休息就过去了。要的是"到了点就真的离开屏幕"——屏幕被占满，倒计时走完才还给你。

## 目标

- 三处各一个开关：微休息、短休息、长休息，互不影响。
- 开了的开关一触发，全屏遮罩出现，上面只有一个倒计时。
- 遮罩期间关不掉：没有跳过按钮、没有标题栏、Esc / F5 无效、Alt+F4 和点击关闭都被拦下。
- 倒计时自然走完，遮罩自己消失，回到原来的迷你窗（休息结束 → 继续专注）。

## 非目标

- 不做惩罚、不做强制休息次数统计。
- 不做每块显示器一块遮罩（只盖主显示器）。
- 不改任何计时、写记录、同步逻辑。
- 不阻止你从托盘退出程序——见下面的逃生口。

## 约束

- Tauri 2 + 纯 HTML/JS 前端，不加新依赖。
- 计时状态已经在后端（`timer.rs` / `micro_break.rs`），前端只是视图；遮罩也是视图，不能成为状态的来源。
- 配置放 `config.json`（Rust 侧要读），走现有 `get_config` / `save_config`。

## 选过的三条路

- **A. 新增独立全屏窗口 `break-screen`**（选它）：跟现有窗口互不干扰，休息结束 `hide()` 就回到原界面；遮罩出问题最多是不弹，不会碰到计时。
- **B. 复用主窗口 + `set_fullscreen(true)`**：主窗是 662×1065 的完整界面（侧栏 + 三个页签），全屏后要整成遮罩样式、结束后还要还原尺寸和位置；主窗被收进托盘时是隐藏的，得先弹出来。改动面更大，放弃。
- **C. 无边框窗口手动铺满显示器**：和 A 类似，但要自己算显示器尺寸与位置，150% DPI 与多显示器下更容易错位，没有换来好处。放弃。

## 怎么实现（A）

**配置**：`Config` 增 `force_break: ForceBreak { micro: bool, short: bool, long: bool }`，`#[serde(default)]`，默认全关。设置页在「随机微休息」之后加分组「强制模式」，三个 `checkbox.sw`，改了立即保存（跟「定时触发思源同步」一个风格）。

**窗口**：label `break-screen`，加载 `break-screen.html`，`fullscreen(true)`、`decorations(false)`、`always_on_top(true)`、`skip_taskbar(true)`、`resizable(false)`。第一次需要时创建，之后复用，只做 show/hide。

**谁来决定显示**：都在后端，前端不判断。

- 短/长休息：计时后台线程每 250ms 已经在看状态，顺手加一条——`kind` 是 `shortBreak` / `longBreak` 且 `status == Running` 且对应开关开着 → 显示遮罩；任何一条不满足 → 隐藏遮罩。窗口操作放在锁外做。
- 微休息：`micro_break.rs` 的弹窗分支里，开关开着就显示全屏遮罩（不开还是原来 300×250 的小窗）；微休息结束时隐藏。
- 两个来源不会撞：微休息只在番茄专注运行时才触发，休息时它压根不会启动。

**遮罩窗口归谁**：记一个 `owner`（`micro` 或 `break`），只有当前 owner 才允许隐藏，避免两条线互相把对方的遮罩关掉。

**页面**：深色底，居中三行——「休息一下」/ 大号 `04:37` / 「还有 4 分 37 秒」。微休息时文案换成「起来动一下」。每 200ms 读一次 `timer_get`、`micro_break_get`，到点后端会把状态改成已结束，显示 00:00 后窗口就被隐藏，页面不需要自己关自己。

**锁定**：`on_window_event` 里对 `break-screen` 的 `CloseRequested` 只 `prevent_close()`、不 hide（现有代码对所有窗口都是 prevent_close 后 hide，这里要特判）。前端再拦 `contextmenu` 和 Esc / F5 / Ctrl+R 的按键。

**逃生口**（我的判断，你没有反对就按这个来）：托盘菜单的「退出」保留可用；任务管理器强杀自然有效。除此之外没有出口。

**失败时的行为**：窗口创建或显示失败，记一笔日志并跳过遮罩，计时与写记录照常——遮罩坏了不能连带影响番茄本身。

## 测试要点

- `cargo check` 通过；`break-screen.html` 用桩页面在浏览器里看排版（150% DPI）。
- dev 版真机三条：微休息（设 10 秒间隔）强制、短休息强制、长休息强制各来一次，看遮罩出现 → 倒计时 → 自动消失 → 迷你窗回到正确状态。
- 锁定四条：Esc、Alt+F4、托盘「打开主窗口」、点击遮罩——遮罩都还在；托盘「退出」能退出。
- 关掉某个开关后，对应的休息回到原行为（微休息还是 300×250 小窗，休息只在迷你窗里倒计时）。

## 留给实现时的判断

遮罩的具体配色、字号、文案细节；倒计时最后 10 秒要不要变红；休息结束后是否自动接续下一个番茄（现状是不自动，保持现状）。
